## Antes da entrega

1. Extraia o ZIP em uma pasta nova.
2. Execute `ABRIR_TERE_VERDE.vbs`.
3. Valide login administrativo.
4. Cadastre uma atração, um evento e um aviso com foto.
5. Confira a página pública e a faixa de aviso urgente.
6. Execute `npm test` na pasta `backend`.
7. Publique no GitHub e confirme se o README aparece corretamente.
8. Faça um ensaio do pitch seguindo o Word de apresentação.
